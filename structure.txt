NOTES ON KEY FILES
---------------------
- ai_agent.py    : Core AI module — handles language detection (Hindi/
                    Hinglish/English), intent classification, GPT-4o /
                    Claude response generation, structured order
                    extraction (JSON), and confidence-based escalation.

- whatsapp.py    : Handles incoming/outgoing WhatsApp messages via
                    Twilio API, Meta Cloud API, or the Mock Provider
                    used for local testing.

- main.py        : Defines all REST API endpoints and webhook routes
                    (e.g. /webhook/twilio, /webhook/meta, /api/orders,
                    /api/analytics).

- models.py      : Defines database tables — Business, Customer,
                    Conversation, Order, OrderItem, Notification.

- Dashboard.jsx  : Main UI for business owners — view chats, orders,
                    and pending human-escalation alerts.

- Analytics.jsx  : Visual insights using Recharts — order trends,
                    customer engagement, response stats.
